## Implementation Notes

- 3.1〜4.1: 試験の順序・到達の確認・ログインの失効・中断は `scenarios/run.test.ts` で確かめる。結果の表示と成果物（results.json・summary.txt・run.json）は main.ts が書き、秘密の検査は `common/report.ts` の writeReport が担う。成果物は設計の `<日時>.json` ではなく、ディレクトリ形式にした（共有の writeReport に合わせた）
- Proton の接続は接続先を指定せず自動接続（`connectAuto`、無料でも可）で行う。無料プランの接続先の指定は、接続先の一覧が 403 になるため、API が 403（operation_restricted）で拒否する（4.5）
- AdGuard は自動接続を持たず、接続先の指定が必要。無料版の接続先指定の応答は 2.6 の実機の観測で確定するまで、無料版の試験（3.4 の無料側・3.5）は保留
- Ctrl-C は、次の試験の前に止める。出口 IP の観測の途中（最大 180 秒）は、観測が終わるまで待つ。設定の復元は止まった後に必ず行う
- 2.5・3.2〜3.4・4.2・4.3 の完了は、実機の試験（5.3〜5.5）で合格を確かめてから [x] にする
