# Phase 24: ログインボタンもプルダウンの隣へ・入力欄の枠線色をボタン同等の薄さへ

## 目的

Phase 23実施後の利用者からの指摘（資格情報入力型ログインのフォームがプルダウンの隣ではなく下に大きく表示されたままであること、入力欄・プルダウンの枠線のグレーが濃すぎること）を受け、Web UIの表示のみを改善する。機能追加・API変更は行わない。

## 前提

- Phase 23（ベンダー選択のプルダウン化・PWA対応・モバイル表示の改善）が完了していること。

## スコープ外

- API・データモデルの変更（本フェーズはWeb UIの表示のみ）。
- URL提示型ログインボタンの表示文言の変更（「VPNベンダーへログイン」のまま維持し、資格情報入力型のみ「ログイン」ボタンを新設する）。

- [x] `specs/webserver/requirements.md`「ログインボタンもプルダウンの隣へ・入力欄の枠線色をボタン同等の薄さへ（Phase 24）」に要件を追記
- [x] `specs/webserver/design.md`に実装方針を追記
- [x] `SessionCard.tsx`に`showCredentialsForm`状態を追加し、資格情報入力型ログインも「ログイン」ボタンをプルダウンの隣（`session-action`）に表示、押すまでフォームを表示しないよう変更
- [x] `styles.css`の`--input-border`をボタンの枠線色（`--border`、`#d0d7de`）と同じ値へ変更
- [x] 既存コンポーネントテスト（`App.provider.test.tsx`）を「ログイン」ボタンのクリックを挟むよう追従修正
- [x] 検証環境（実機、`ubuntu@192.168.3.240`）のブラウザ（Playwright）で確認、恒久的なE2Eスクリプト（`e2e/phase24/webgui-phase24.mjs`）を追加

## 完了基準

- `web`のユニット/コンポーネントテスト（`npm test`）がFAIL 0であること。
- 検証環境のブラウザで、①資格情報入力型ログインのベンダーでも未ログイン時にプルダウンの隣へ「ログイン」ボタンが表示されクリックするまでフォームが表示されないこと、②クリック後にフォームが表示されること、③入力欄・プルダウンの枠線色がボタンの枠線色と同程度の薄いグレーになっていることを確認する。

## 検証手法

`web`のユニット/コンポーネントテスト（`npm test`）、`npm run build`・`tsc`（型チェック）、`scripts/check-vendor-neutrality.mjs`を実行する。実機は検証環境（`ubuntu@192.168.3.240`）の`web`コンテナを本フェーズの資材で再ビルド・再起動し、Playwrightで、プルダウン・入力欄の`getComputedStyle`の`borderColor`（ボタンの枠線色`rgb(208, 215, 222)`と一致すること）、「ログイン」ボタンの行内配置、クリック前後のフォームの表示・非表示を確認する。検証は実際のログイン送信を行わない（フォームを開くところまでに留める）ため、検証環境の状態（選択中ベンダー・ログイン状態・VPN接続状態）は変化しない。

## 検証結果（2026-09-22、検証環境ubuntu@192.168.3.240）

- `npm test`（web）: FAIL 0（103件PASS。「ログイン」ボタンのクリックを挟むよう追従した`App.provider.test.tsx`の修正を含む）。
- `tsc -p tsconfig.json --noEmit`・`npm run build`: エラー無し。
- `scripts/check-vendor-neutrality.mjs`: OK（禁止語12語）。
- 実機（`web`コンテナのみ本フェーズの資材で再ビルド・再起動。`api`・`proxy`・`runner-*`は未変更のため未再ビルド）をPlaywright（`e2e/phase24/webgui-phase24.mjs`）で確認:
  - 検証開始時点で選択中のProton VPN（資格情報入力型、未ログイン）で、プルダウンの隣（同じ行）に「ログイン」ボタンが表示されることを確認。
  - ボタンをクリックする前は、ユーザー名・パスワード等の入力欄が画面上に存在しないことを確認。
  - ボタンをクリックすると、プルダウンの下の行へログインフォーム（ユーザー名・パスワード欄を含む）が表示されることを確認。
  - プルダウン・パスワード入力欄の`getComputedStyle`で、`borderColor`が`rgb(208, 215, 222)`（ボタンの枠線色`--border`と同じ）になっており、Phase 23時点の濃いグレー（`rgb(110, 119, 129)`）・Phase 22以前の紫（`rgb(110, 64, 201)`）のいずれでもないことを確認。
  - 検証は実際のログイン送信を行わずフォームを開くところまでに留めたため、検証環境の状態（選択中ベンダー: Proton VPN、未ログイン、VPN切断）は変化していないことをAPI（`GET /v1/providers`・`/v1/connection`・`/v1/session`）で確認。
